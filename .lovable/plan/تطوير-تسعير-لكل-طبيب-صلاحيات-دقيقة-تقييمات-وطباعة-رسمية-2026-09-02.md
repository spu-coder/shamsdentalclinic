# تطوير: تسعير لكل طبيب، صلاحيات دقيقة، تقييمات، وطباعة رسمية

## 1) تسعير الخدمة لكل طبيب + قائمة خدمات لكل طبيب
- جدول جديد `doctor_services` يربط الطبيب بالخدمة ويحدد: السعر الخاص، مدة الجلسة، الحالة (مفعّل/موقوف).
- الطبيب/المدير يضيف أو يزيل الخدمات التي يقدّمها ويحدد سعره الخاص لكل خدمة، مع السعر الأساسي كقيمة افتراضية.
- في صفحة الحجز: عند اختيار الطبيب تُعرض خدماته فقط مع سعره وليس القائمة العامة.
- في صفحة الخدمات العامة: يُعرض نطاق السعر (من — إلى) بحسب الأطباء.
- الفاتورة تأخذ السعر من تسعيرة الطبيب الفعلية.

## 2) تقييم المريض للطبيب
- جدول `doctor_reviews`: نجوم من 1 إلى 5 + تعليق + الموعد المرتبط.
- المريض يقيّم فقط بعد موعد مكتمل، تقييم واحد لكل موعد، ويمكنه تعديل تقييمه.
- يظهر متوسط التقييم وعدد التقييمات في صفحة الفريق وبطاقة الطبيب؛ المدير يستطيع إخفاء تقييم مسيء.

## 3) فصل الصلاحيات بدقة
- الطبيب: يرى ويقبل/يرفض مواعيده فقط، ويرى ملفات مرضاه فقط (من له موعد أو زيارة معه). لا يظهر له زر حجز موعد لنفسه ولا مواعيد أطباء آخرين.
- الموظف (staff): إدارة المواعيد والفواتير لكل الأطباء دون بيانات إدارية حساسة.
- المريض: ملفه فقط.
- د. ياسر (مدير المركز): صلاحية كاملة على كل شيء — كل المواعيد، كل المرضى، الأطباء، الخدمات، التسعير، الفواتير، التقارير، التقييمات.
- التنفيذ على مستويين: إخفاء/تعطيل في الواجهة + سياسات حماية في قاعدة البيانات حتى لا يستطيع طبيب قراءة أو تعديل بيانات طبيب آخر.

## 4) تعديل الملفات الشخصية
- المريض والطبيب يعدّلان الاسم وبيانات التواصل والصورة.
- الطبيب يعدّل أيضاً اللقب والاختصاص والنبذة وصورته المهنية الظاهرة في الموقع.
- المدير يعدّل أي ملف.

## 5) طباعة رسمية للفواتير والتقارير (تيمبليت مطبوع، ليس لقطة شاشة)
- قالب طباعة مستقل بحجم A4 وبهوية المركز: اللوغو، الاسم العربي والإنجليزي، العنوان والهواتف، ألوان فيروزي/فضي.
- فاتورة رسمية: رقم الفاتورة، تاريخها، بيانات المريض، الطبيب، بنود المعالجة والأسعار، الحسم، الإجمالي، الدفعات، المتبقي، وملاحظة شكر.
- تقرير طبي/مالي/تاريخي بنفس القالب مع جداول منسّقة وترقيم صفحات.
- تذييل رسمي فيه توقيع د. ياسر زكريا شمس الدين وختم المركز (صورة توقيع + ختم دائري بالهوية) — يظهران في الطباعة والـ PDF.
- زر «طباعة / حفظ PDF» يفتح القالب فقط دون قوائم الموقع.

## تفاصيل تقنية
- ترحيل قاعدة بيانات: `doctor_services` و`doctor_reviews` + سياسات وصول ومنح صلاحيات، ودالة مساعدة `is_my_patient(doctor, patient)` و`current_doctor_id()` لتقييد الطبيب.
- تحديث سياسات `appointments` و`visits` و`invoices` و`visit_media` لتقييد دور doctor بمرضاه، مع بقاء admin على وصول كامل.
- `useAuth` يضيف `doctorId` و`isDoctorOnly` لاستخدامها في تصفية الواجهات.
- مكوّنات جديدة: `PrintLayout` (قالب A4 + لوغو + توقيع + ختم)، `InvoicePrint`، `ReportPrint`، `DoctorServicesManager`، `ReviewForm` / `DoctorRating`.
- توليد صورتَي التوقيع والختم كأصول ضمن المشروع بهوية المركز.
- تنسيقات الطباعة عبر `@media print` في `src/styles.css`.
