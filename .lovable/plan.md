# موقع عيادة شمس السنية التخصصية — د. ياسر زكريا شمس الدين

منصة كاملة للعيادة: خدمات، حجز مواعيد، ملف طبي وأرشيف، لوحة تحكم للطبيب، تقارير شخصية ومالية وتاريخية، دخول عبر Google، دعم أطباء مختصين متعددين — بالهوية البصرية للشعار (تيركواز/فيروزي + فضي/رمادي غامق).

## الهوية البصرية
- الألوان: فيروزي متدرج (#0FB9C4 → #0E7C8A) أساسي، فضي/رمادي فاتح للأسطح، رمادي داكن (#1E2429) للنص والخلفيات الداكنة، أبيض ناصع للبطاقات.
- الطباعة: عربي حديث (Cairo/Tajawal) للعناوين والنصوص + أرقام لاتينية واضحة. اتجاه RTL كامل.
- الأسلوب: نظيف طبي، زوايا ناعمة، ظلال خفيفة، أشعة الشمس من الشعار كعنصر تزييني، أنيميشن هادئ (ظهور تدريجي عند التمرير، تحويلات ناعمة، حالات تحميل هيكلية) — بلا مبالغة.
- الشعار المرفوع يُستخدم في الهيدر والفوتر والأيقونة.

## واجهة الزوار (عامة)
1. الرئيسية: هيدر بالشعار، بطل مع اسم الطبيب والتخصصات (جراحة – تقويم – معالجات لبية ولثوية – تجميل)، زر "احجز موعد" وزر اتصال مباشر 0959405017.
2. الخدمات: صفحة لكل خدمة مع وصف ومدة تقديرية وسعر إرشادي.
3. الفريق: بطاقات الأطباء المختصين داخل المركز.
4. قبل/بعد ومعرض صور (اختياري لاحقاً).
5. تواصل: خريطة/وصف الموقع (عين منين – طريق حلبون – جانب صيدلية طحلة)، ساعات العمل، واتساب واتصال.
6. SEO عربي: عناوين ووصف لكل صفحة + بيانات منظمة Dentist/LocalBusiness.

## حساب المريض
- تسجيل دخول Google (وبريد/كلمة مرور كخيار).
- حجز موعد: اختيار الطبيب → الخدمة → يوم ووقت من الأوقات المتاحة فعلياً → تأكيد. الحالة: بانتظار الموافقة / مقبول / مرفوض / مكتمل / ملغى.
- مواعيدي: القادمة والسابقة، إلغاء أو طلب تعديل.
- ملفي الصحي: استبيان صحة عامة (أمراض مزمنة، أدوية، حساسية، حمل، تدخين، ضغط/سكر…) قابل للتحديث.
- الأرشيف: زيارات سابقة، تشخيص، معالجات، صور أشعة ومرفقات، وصفات.
- الفواتير: المدفوع والمتبقي وطباعة PDF.

## لوحة الطبيب / الإدارة
- تقويم يومي/أسبوعي/شهري مع سحب وإفلات للمواعيد.
- إدارة الأوقات: ساعات العمل لكل طبيب، مدة الجلسة، فواصل، أيام عطل، إجازات، حجب أوقات.
- قبول/رفض/تأجيل الطلبات مع سبب، وإشعار المريض.
- ملف المريض: مخطط أسنان (Odontogram) بترقيم FDI لتوثيق كل سن، خطة معالجة بمراحل، ملاحظات سريرية، رفع صور/أشعة.
- تقرير الصحة العامة لكل مريض: تجميع الاستبيان + تنبيهات خطر (سيولة دم، حساسية بنسلين، سكري…) تظهر أعلى الملف.
- المالية: تسعير الخدمات، فاتورة، دفعات جزئية، خصومات، متبقي، صندوق يومي.
- الأطباء والمستخدمين: إضافة طبيب مختص، تخصصه، أوقاته، صلاحياته (مدير / طبيب / سكرتارية / مريض).
- سجل تدقيق (من عدّل ماذا ومتى).

## نظام التقارير (استخراج PDF/Excel/طباعة)
مفرداً (لمريض واحد) وجماعياً (لكل العيادة) مع فلاتر: التاريخ، الطبيب، الخدمة، حالة الدفع، العمر/الجنس.
- شخصية: بطاقة المريض، تقرير الصحة العامة، تقرير حالة الأسنان، خطة المعالجة، تقرير زيارة، تقرير إحالة/إجازة مرضية.
- تاريخية: سجل الزيارات الزمني، تاريخ المعالجات لكل سن، سجل الإلغاءات والغياب.
- مالية (مفرد): كشف حساب المريض، الفواتير، الدفعات، المتبقي.
- مالية (جماعي): إيرادات يومي/شهري/سنوي، إيراد لكل طبيب، إيراد لكل خدمة، الذمم المدينة، مقارنة الفترات.
- تشغيلية: عدد المواعيد ونسب الحضور/الغياب، إشغال أوقات الطبيب، المرضى الجدد مقابل المراجعين، أكثر الخدمات طلباً.
- كل تقرير: رأس بالشعار واسم الطبيب والعنوان والهاتف، تاريخ الإصدار، ترقيم صفحات، جاهز للطباعة.

## الأمان
- Lovable Cloud للبيانات والدخول والتخزين.
- سياسات صلاحيات على مستوى الصف: المريض يرى بياناته فقط، الطبيب يرى مرضاه، المدير يرى الكل.
- الأدوار في جدول مستقل (منع تصعيد الصلاحيات)، والتحقق يتم على السيرفر لا في المتصفح.
- ملفات الأشعة في تخزين خاص بروابط موقّعة مؤقتة.
- تحقق من المدخلات على الطرفين، حماية من الحجز المزدوج، سجل تدقيق كامل.

## الأجهزة والأداء
تصميم موبايل أولاً (أغلب الحجوزات من الجوال)، أزرار اتصال/واتساب ثابتة على الجوال، تقويم يتحول لقائمة على الشاشات الصغيرة، دعم RTL كامل، صور محسّنة وتحميل تدريجي.

## مراحل التنفيذ
1. الهوية البصرية + الموقع التعريفي (رئيسية، خدمات، فريق، تواصل) — يعمل فوراً.
2. تفعيل Cloud + دخول Google + جداول المرضى والأطباء والمواعيد والصلاحيات.
3. الحجز للمريض + لوحة الطبيب لإدارة الأوقات والقبول.
4. الملف الطبي: استبيان الصحة، مخطط الأسنان، خطة المعالجة، المرفقات، الأرشيف.
5. الفواتير والدفعات.
6. محرك التقارير (مفرد + جماعي) مع التصدير والطباعة.
7. إشعارات (بريد/واتساب) وتذكير بالمواعيد + لمسات الأنيميشن والتشطيب.
